# 嘉猎前端改造

采用暖白、炭黑、鸢尾紫与低饱和铜色，桌面固定可收起侧栏与非对称探索首页，围绕「明确需求 → 发现人才 → 收藏对比 → 核实经历」组织工作台。移除雷达、轨道、装饰柱状图；`design.css` 统一负责视觉样式，不再叠加旧的 `styles.css` 与 `chat.css`。保留 React、Ant Design、现有 API 和鉴权，使用 Motion 提供轻量交互反馈。

## 交互

- 搜索首页：三种场景填入可编辑的招聘需求；展示真实人才库数量和最近会话。
- 会话：支持历史搜索、切换、确认删除、继续追问、请求进度和失败后恢复草稿。中文输入法确认不会误发送，Shift + Enter 换行。
- 候选人：展开原文引用、查看匹配亮点和待核实信息、跳转完整档案；不展示内部评分分项和运行轨迹。
- 导航：桌面固定侧栏可收起为图标，顶部固定新搜索、导入入口；路由即时切换，取消整页入场动画；Ctrl / Cmd + K 快捷导航；移动端侧栏与遮罩；尊重系统减少动态效果偏好。
- 探索首页：文字分段显现，背景光束沿曲线流动，可暂停/播放，离屏和后台自动停止。分层卡片跟随鼠标旋转，点击可输入需求或打开人才库。输入框与场景卡片有鼠标跟随描边，场景按钮有弹簧抬升反馈，原文证据有展开过渡。
- 小屏隐藏辅助卡片与键盘快捷键提示，保留搜索主任务。减少动画样式仅作用于自有组件，避免破坏 Ant Design 弹层生命周期。
- 招聘概览取代人才雷达，呈现真实档案数、最近岗位、收藏数和异常简历；每项数据均能进入对应工作流。
- 岗位支持创建、关键词和行业筛选、按是否已有推荐筛选、查看岗位详情和重新匹配。手动岗位直接使用现有岗位匹配接口，不再跳转到空白问答页。时间字段明确标为创建时间。
- 人才库支持姓名、职位、技能、文件名检索，城市、经验和处理状态筛选，以及拖放批量导入。分别反馈接收、重复和拒绝数量，空结果可清空筛选。
- 推荐卡、人才库和档案可收藏候选人；收藏页支持 2–3 人并排对比所在地、经验、行业、技能、管理经历与履历亮点。仅将候选人 ID 保存在当前浏览器，个人资料始终从鉴权 API 读取，失效档案可取消收藏。
- 登录、招聘概览、岗位、人才库、收藏与设置共享视觉样式。调用审计从客户路由和导航移除，服务端记录继续保留。
- 设置分为「使用偏好」和「模型接入」。使用偏好包含发送快捷键、展示人数和自动展开证据，保存于当前浏览器，支持恢复默认。
- 模型接入供服务负责人管理对话与检索服务；重排和运行参数继续内置。服务错误转为可执行提示，内部请求 ID 保留用于排查。

## Aceternity UI

从官方公开 registry 取得组件实现并适配本项目的普通 CSS，不额外引入 Tailwind：

- `src/components/ui/card-hover-effect.tsx`：基于 [Card Hover Effect](https://ui.aceternity.com/components/card-hover-effect)，保留 Motion 共享布局背景和 AnimatePresence，改为可键盘操作的按钮，增加焦点与减少动画支持。
- `src/components/ui/background-beams.tsx`：基于 [Background Beams](https://ui.aceternity.com/components/background-beams)，保留曲线与 SVG 渐变动画，改为 18 条确定性光束，增加暂停、可见性和减少动画支持。
- `src/components/ui/text-generate-effect.tsx`：基于 [Text Generate Effect](https://ui.aceternity.com/components/text-generate-effect)，按中文短句交错显现。
- `src/components/ui/glowing-effect.tsx`：基于 [Glowing Effect](https://ui.aceternity.com/components/glowing-effect)，使用指针角度插值、渐变遮罩和帧调度实现描边。
- `src/components/TalentCanvas.tsx`：基于 [3D Card](https://ui.aceternity.com/components/3d-card-effect) 的透视/指针旋转思路，适配为两个真实操作入口；不使用虚构候选人或匹配数据。
- `src/components/ui/spotlight.tsx`：基于 [Spotlight](https://ui.aceternity.com/components/spotlight)，保留 SVG 柔光，实现独立滤镜 ID，用于登录页。

## 本地启动

后端继续使用仓库 README 中的启动流程；前端执行 `npm install`、`npm run dev -- --host 127.0.0.1`，默认代理 `http://localhost:8010`。前端检查为 `npm run build` 和 `npm test`。

演示使用仓库自带 `scripts.seed_demo` 虚构简历与离线 Mock 模式。服务负责人可在「设置 → 模型接入」配置服务，或继续使用 `.env`；更换检索模型后需更新索引。

## 切页与连续工作

- 仅保留已经访问的六个工作页面，搜索草稿/会话、筛选、对比勾选和滚动位置不因切页丢失；不写入浏览器存储，退出登录时清空。候选人详情按需卸载。
- 页面代码在悬停/键盘聚焦导航时预加载，初次进入后错开预加载其余页面。每个页面独立 Suspense，避免替换整个工作区。
- 返回页面保留已有内容并后台刷新；隐藏页面关闭弹层、暂停轮询、停止背景光效，不抢滚动。每个页面保留自己的路由参数，避免其他页面的查询参数重置筛选。
- 已实测搜索草稿、人才库筛选、档案返回、滚动恢复、岗位抽屉隔离、收起侧栏、导入定位和手机导航。

## 内页编排

- 共用 `StudioHeading` 的编号、标题和分色排版，按各页任务组织不同结构，沿用搜索首页的炭黑、暖白、紫灰与铜色。
- 招聘概览：招聘简报与人才资产并列，下接紧凑数据条、岗位进展和下一步行动；根据实际待匹配数切换文案。
- 招聘岗位：左侧需求目录和状态筛选，右侧编号档案；原有创建、筛选、匹配、删除和抽屉操作保留。
- 人才库：档案概览与批量导入并列，下方是带技能摘要的名册；继续支持城市、经验、处理状态筛选。
- 收藏：三个实时对比席位，可以直接移除已选人选；下方候选人档案卡选中高亮，对比操作栏保持可见。
- 设置：左侧随草稿变化预览发送方式、展示人数和证据展开方式，右侧集中操作；保存后应用。
- 候选人详情：档案封面、经历脉络、履历亮点与原文核实分区，延续档案主题。
- Aceternity Glowing Effect 复用于简报、岗位和收藏卡片及导入区。页面切换不添加整页入场等待，不改变上轮状态保留行为。

验证：6 个内页在 1440 / 820 / 390 像素宽度下检查无横向溢出；对比席位、设置实时预览与保存、岗位筛选/详情/描边均已实测，原有筛选、导入、收藏与证据操作通过回归。

## 模型接入与本轮验收

- 对话支持 DeepSeek、阿里云百炼、硅基流动、智谱、OpenAI，以及自定义 OpenAI 兼容服务；一次启用一套对话服务和一套检索服务。预设模型名称可修改，不保证服务商账户均有权限。
- 检索服务独立配置地址、模型与密钥；自定义服务使用模型原生输出维度。标准预设自动填写维度，技术选项折叠。
- 先测试草稿，再保存；测试只发送示例文字。离线演示明确显示未连接远程服务。页面离开时清空输入的密钥，不写入浏览器存储。
- 配置保存在服务端 `.env`；部署环境变量优先于文件。仓库当前仅有 AdminUser，模型管理入口尚无独立客户角色隔离；开放客户账号前须增加授权机制。
- 更换检索服务后，在后端虚拟环境执行 `python -m scripts.reindex_embeddings --force`，成功后重新读取配置。失败批次返回非零状态并保留待更新标记，避免误报就绪。
- 岗位列表缩短卡片、收紧目录宽度，增加排序与直接推荐操作；新建岗位后自动打开详情，可以立即匹配。
- 浏览器实测：鉴权、演示连接检查与保存、离页密钥清空、虚构 DOCX 导入解析、建岗匹配、自然语言搜索与追问、原文证据、收藏对比、390/820 宽度检查均通过；本轮导入与业务记录已清理。
- 未提供真实模型密钥，云端服务连通性和真实语义检索效果尚未验收。
